Offline downloader

Il tuo film, quando ti serve.

Copia un URL del player Vixcloud e avvia il flusso manuale. Il file sarà disponibile nella pagina del processo per tre giorni.

Apri Actions

  1. In GitHub premi Run workflow.
  2. Incolla l’URL e conferma di avere il diritto al download.
  3. Al termine, scarica l’artefatto video-vixcloud.

Usa questo strumento esclusivamente per contenuti tuoi, autorizzati o di pubblico dominio. Non aggira DRM, account o controlli di accesso.
